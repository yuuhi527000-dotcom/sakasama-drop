# さかさまドロップ

4つつなげて消す落ちものパズル。ゲージが溜まったら相手の盤面を上下反転！

## ファイルの中身

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `css/style.css` | 見た目（色・ボタン・配置） |
| `js/config.js` | **バランス調整はここ**（本家ぷよぷよ通の実測値に合わせた落下・時間・対戦ルール、ゲージ量など） |
| `js/board.js` | 盤面のルール（連鎖・反転・いし） |
| `js/player.js` | 1人分の進行（操作・固定・攻撃） |
| `js/cpu.js` | CPU（よわい／ふつう／つよい） |
| `js/render.js` | つぶと盤面の描画 |
| `js/input.js` | 操作（キー・ボタン）と効果音 |
| `js/main.js` | 画面切り替え・試合の進行 |
| `js/online.js` | 合言葉オンライン対戦（部屋・送受信・観戦） |
| `js/firebase-config.js` | オンライン対戦の接続先（Firebase） |
| `database.rules.json` | Firebaseのデータベースに貼る安全ルール |
| `manifest.json`・`icons/` | ホーム画面に追加したときの名前・アイコン・全画面設定 |

## 操作

- **PC**：← → いどう／↓ はやく落とす／↑ 一気に落とす／Z 左回転／X・スペース 右回転／Shift 相手をさかさま／C 自分をさかさま
- **スマホ（ボタン）**：◀ ▶ いどう／▼ はやく落とす／⤓ 一気に落とす／↺ ↻ 回転／相手に・自分に スキル
- **スマホ（なぞる）**：左右になぞっていどう／下になぞって落とす／下にはじいて一気に落とす／画面の左タップで左回転・右タップで右回転
- なぞる操作はボタン表示のときも使える。「なぞる」にするとボタンが消えて画面が広くなる（タイトル画面か一時停止メニューで切り替え）
- スマホを横にすると、自分と相手の盤面が同じ大きさで並ぶ画面になる（左で移動、右で回転とスキル）

## スマホでアプリのように遊ぶ

公開したURLをスマホで開き、ブラウザの共有メニューから「ホーム画面に追加」をすると、アイコンから全画面で起動できます（`manifest.json` と `icons/` がその設定）。

## 手元で遊ぶ

`index.html` をダブルクリックするとブラウザで開けます。

## GitHub Pagesで公開する

1. GitHubで新しいリポジトリを作る（公開設定：Public）
2. このフォルダの中身をすべてアップロード（`index.html` が一番上に来るように）
3. リポジトリの「Settings」→「Pages」→ Branch を `main` / `/(root)` にして保存
4. 数分後に表示されるアドレスがゲームのURL

**やめたいとき**：「Settings」→「Pages」で公開を止めるか、リポジトリごと削除すればすぐ消えます。
